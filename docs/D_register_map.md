# D Register Map (Modbus / Internal D-group)

This document lists the D-group Modbus registers used by the application and their meanings.

Notes
- All code stores registers as 16-bit values; byte offsets used in code are `register_number * 2`.
- D-range persist: `D130..D159` are persisted to NVS by `EzApp::saveD130RegionToNVS()` / restored by `EzApp::loadD130RegionFromNVS()`.
- Files with implementations: main/ez_dio.cpp, main/modbus_master.cpp, main/modbus_slave.cpp, main/ezapp.cpp

Summary table
| Register (D#) | Byte offset | Name / purpose | Notes / source |
|---:|---:|---|---|
| D0  | 0    | Loop counter (debug) | Written in `ez_dio` loop
| D100| 200  | Digital inputs (PCF8574 read) | HMI/monitoring
| D101| 202  | Digital outputs (PCF8574 write) | HMI/monitoring
| D102| 204  | Control mode / curing step selector | `curing_step_addr` in `ez_dio.cpp`
| D109| 218  | Voice output number | `voice_out_no_addr` in `ez_dio.cpp`
| D110| 220  | Modbus-polled input value (master result) | Written by `modbus_master.cpp`
| D111| 222  | Analog average / sample storage | Written by `analog.cpp`
| D112| 224  | Humidity (SCD30) x100 | `ez_dio` sensor task
| D113| 226  | CO2 (SCD30) ppm | `ez_dio` sensor task
| D114| 228  | O2 sensor value (E-Oxygen) x100 | `ez_dio` sensor task
| D115| 230  | Temperature (example) x10 (mostly unused) | `ez_dio` commented
| D120| 240  | O2 sensor status (DeviceState enum) | Written by `EzApp::setO2Status()`
| D121| 242  | O2 comm error count | Incremented via `EzApp::incrementO2ErrorCount()`
| D122| 244  | CO2 sensor status (DeviceState enum) | Written by `EzApp::setCO2Status()`
| D123| 246  | CO2 comm error count | Incremented via `EzApp::incrementCO2ErrorCount()`
| D124| 248  | Modbus sensor status (DeviceState enum) | Written by `EzApp::setModbusStatus()`
| D125| 250  | Modbus comm error count | Incremented via `EzApp::incrementModbusErrorCount()`
| D130..D159 | 260..318 | Modbus configuration / D-region persisted area (30 x int16) | Persisted to NVS by `EzApp::saveD130RegionToNVS()` and restored by `EzApp::loadD130RegionFromNVS()`
| D131| 262  | Control input flags (used by control logic) | `ez_dio` reads/writes
| D132| 264  | Control input flags (used by control logic) | `ez_dio` reads/writes
| D140| 280  | Modbus compare/reference value | Used by `modbus_master.cpp` logic
| D142| 284  | Delay/time configuration (ms) for door/actuators | Used by `ez_dio` control logic
| D200..D205 | 400..410 | Special: Modbus write (addr 200..205) mapped to RTC set (year, month, day, hour, minute, second) | Handled in `modbus_slave.cpp` (calls `EzApp::set_rtc_time()`)

DeviceState enum (values stored in D120/D122/D124)
- `0 = DEVICE_KNOWN` — initial / unknown
- `1 = DEVICE_OK` — operating normally
- `2 = DEVICE_ERROR` — device error or not detected
- `3 = DEVICE_INIT_DONE` — initialization completed
- `4 = DEVICE_INIT_PENDING` — initialization in progress

References (code locations)
- `main/ez_dio.cpp` — sensor tasks and D read/writes
- `main/modbus_master.cpp` — modbus polling, writes to D110 and uses D140
- `main/modbus_slave.cpp` — modbus slave read/write handling, RTC set mapping for addr 200..205
- `main/ezapp.cpp` / `main/ezapp.h` — D130..D159 persistence, `DeviceState` enum, `set*Status()` and error counters writing to D120..D125
